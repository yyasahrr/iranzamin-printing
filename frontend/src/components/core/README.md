# 🎨 سیستم طراحی مونو-ریپو چاپ روشن (App Design System Core)

این سیستم طراحی (Design System) به صورت ماژولار و بر پایه اصول فاز سوم PRD توسعه یافته است. طبق **قانون طلایی سیستم**:
> **«هیچ توسعه‌دهنده‌ای اجازه ندارد مستقیماً HTML یا CSS جدید برای یک صفحه بنویسد، مگر اینکه ابتدا بررسی کند آیا کامپوننت یا الگوی موجود قابل استفاده مجدد (Reusable) است یا خیر.»**

---

## 📌 کامپوننت‌های توسعه یافته با پیشوند استاندارد `App`

تمام کامپوننت‌ها به صورت تایپ‌اسکریپت و با قابلیت پشتیبانی از تم‌های تیره/روشن پویا بدون هاردکد کردن رنگ‌ها (مبتنی بر متغیرهای CSS یا Design Tokens) به شکل زیر توسعه یافته‌اند:

### ۱. دکمه استاندارد (`AppButton`)
* **آدرس فایل:** `frontend/src/components/core/AppButton.tsx`
* **امکانات:** پشتیبانی از وضعیت‌های Loading (اسپینر متحرک)، Disabled، اضافه کردن Icon، و ری‌اکتیو بودن کامل.
* **انواع استایل‌ها (Variants):**
  * `primary` (دکمه اکشن اصلی با رنگ سبز نئونی یا آکسنت)
  * `secondary` (دکمه کمکی)
  * `outline` (دکمه حاشیه‌دار شیشه‌ای)
  * `ghost` (بدون پس‌زمینه و حاشیه برای کارتابل‌ها)
  * `danger` (قرمز هشدار/لغو فاکتور)
  * `success` (سبز تسویه موفق)
  * `warning` (نارنجی معلق)
* **نحوه استفاده:**
  ```tsx
  import AppButton from "./components/core/AppButton";
  import { Printer } from "lucide-react";

  <AppButton variant="primary" icon={<Printer size={16} />} loading={isLoading} onClick={handleClick}>
    ثبت سفارش جدید
  </AppButton>
  ```

---

### ۲. کارت هوشمند (`AppCard`)
* **آدرس فایل:** `frontend/src/components/core/AppCard.tsx`
* **امکانات:** مدیریت فاصله‌ها و سایه‌ها به صورت کامپوننت واحد.
* **انواع استایل‌ها (Variants):**
  * `default` (کادر پیش‌فرض و حاشیه نازک)
  * `elevated` (دارای سایه عمیق متحرک)
  * `flat` (رنگ سطح فلت بدون سایه)
  * `interactive` (متحرک و دارای لرزش نرم سه بعدی در زمان هوور ماوس)
  * `statistic` (مرکزی و مناسب برای نمایش اعداد حسابداری)

---

### ۳. فیلدهای ورودی هوشمند (`AppInput`)
* **آدرس فایل:** `frontend/src/components/core/AppInput.tsx`
* **امکانات:** پشتیبانی یکپارچه از انواع فیلدهای متنی، ایمیل، پسورد، شماره تلفن و ناحیه متنی عریض (Textarea) به همراه مدیریت نمایش خطاهای اعتبارسنجی فرانت‌اند و بک‌اند و آیکون‌های جانبی.
* **نحوه استفاده:**
  ```tsx
  import AppInput from "./components/core/AppInput";
  import { Mail } from "lucide-react";

  <AppInput 
    label="ایمیل سازمانی" 
    type="email" 
    icon={<Mail size={16} />} 
    error={emailError} 
    value={email} 
    onChange={(e) => setEmail(e.target.value)} 
  />
  ```

---

### ۴. نشانگرهای وضعیت رنگی (`AppBadge`)
* **آدرس فایل:** `frontend/src/components/core/AppBadge.tsx`
* **امکانات:** یکپارچه‌سازی تمام نشانگرهای وضعیت سفارشات چاپی و تسویه‌حساب‌ها در کل پروژه به صورت کامپوننت مرکزی.
* **انواع وضعیت‌های مورد پشتیبانی (Status):**
  * `pending` (در انتظار بررسی فایل - زرد ملایم)
  * `processing` (در حال طراحی - آبی آسمانی)
  * `printing` (در حال چاپ - بنفش لوکس)
  * `ready` (آماده تحویل - سبز)
  * `shipped` (ارسال شده - آبی تیره)
  * `cancelled` (لغو شده - قرمز ملایم)
  * `paid` (تسویه موفق)
  * `unpaid` (پرداخت نشده)
  * `refunded` (مرجوع شده)

---

### ۵. پنجره‌های تعاملی پاپ‌آپ (`AppModal`)
* **آدرس فایل:** `frontend/src/components/core/AppModal.tsx`
* **امکانات:** سیستم انیمیشن‌های روان Framer Motion به صورت همگن در سراسر پلتفرم.
* **اندازه‌های استاندارد (Sizes):**
  * `sm` (۴۰۰ پیکسل)
  * `md` (۵۵۰ پیکسل)
  * `lg` (۷۵۰ پیکسل)
  * `xl` (۱۰۰۰ پیکسل)
  * `fullscreen` (تمام صفحه برای کارتابل‌های سنگین)

---

## 🚀 تعهد ۱۰۰ درصدی به توسعه پایدار

با استقرار این سیستم طراحی در لایه هسته (`components/core/`):
1. **توسعه‌پذیری تا بی‌نهایت:** حتی در صورتی که تعداد صفحات پنل‌های کاربری و ادمین به بالای ۲۰۰ صفحه برسد، هویت بصری سایت در تمام پلتفرم‌ها کاملاً هماهنگ، یکپارچه و فاقد هرگونه تضاد استایل یا تداخل کدهای CSS متفرقه خواهد بود.
2. **بروزرسانی متمرکز:** هرگونه تغییر در ابعاد، انیمیشن‌ها یا افکت دکمه‌ها و فیلدها در آینده تنها با ادیت ۱ فایل در این دایرکتوری، در سراسر پلتفرم بزرگ چاپخانه بازتاب خواهد یافت.
